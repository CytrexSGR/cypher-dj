# Layouts for the A10 cost instrument (--werkzeuge in kosten25.sh / kosten25_sender.py, layouts in kosten25.cpp).
# One source for the sender, the shell script and the offline program. Line format (blank lines and # comments ignored):
#   layout NAME            starts a layout
#   konfig KEY VALUE       kern.toml line the layout needs (kosten25.sh writes it into the run's kern.toml)
#   zeile PATH NUMBER      one row set with the OSC message of the hand's server path (/k/teil, quelle andreas, a beat ahead)
# Strict grammar, the same in kosten25.sh, kosten25_sender.py and kosten25.cpp: '#' comments and blank lines only; unknown keyword, wrong token
# count, malformed or non-numeric value, CR/VT/FF outside a comment (CRLF files), a line before the first layout, duplicate layout/key/path are errors (exit 4). Row counts are
# pinned in all three: aus 0, limiter-gebaut 4, typisch 19, voll 76.
# Paths and ranges: docs/architecture/stand/mix-werkzeuge.md and the 345-row table (plan A, section 3); every value is inside its range.
# aus             tools off, all rows at default, limiters not built (kanal_limiter_vorhalt_ms 0): today's cost
# limiter-gebaut  limiters built (vorhalt 5 ms), all four lim/an explicitly 0: the pure cost of the latency account
# typisch         2 gates (hard), 4 utilities, 1 multiband compressing, 1 limiter (no true peak), spectrum on master
# voll            13 gates (ratio mode), 17 utilities with bass mono, 4 multibands compressing, 4 limiters with true peak, spectrum
